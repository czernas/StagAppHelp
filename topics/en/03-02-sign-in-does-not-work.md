## The most common cause of a broken login is due to a limitation of the STAG server API. This limitation occurs for example:

- **Entering incorrect password** and subsequent blocking for a few tens of minutes (if the wrong password is entered again).
- **Wrong username.**
- **Recent password change** -> this password may not have been saved on the STAG server yet. In this case, try to use the original password.
- **You're starting your first year** and the semester has not yet started -> Your account is not yet unblocked for external use (in the app).

### Studying at UPCE, TUL, ZČU, VFU, UHK, JČU, OSU?

In this case, you use a web form to log in. You need to log in using the **Školní přihlašovací údaje** part, not using the _Databáze uživatelů IS/STAG_.

![](webview_login.jpeg)

### Studying at TUL?

In this case, you use a web form to log in. You need to log in using the **Jednotné přihlášení TUL** part, not using any other option.

![](webview_login_tul.png)

### Studying at OSU?

A common cause of a non-functioning OSU login is the need to use the initial password that was assigned to you when you started your studies. So try logging in with that password. If you have already tried the previous steps and even this does not help, you need to contact your university's network administrator about the API login issue.

## None of the above solutions help?

Contact us via the Feedback in **Menu**, add your login name, university and an email to which we will contact you back for additional information.
