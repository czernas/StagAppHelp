## Types of display

The timetable can currently be displayed in two forms, namely:
- As a list, where individual timetable activities are arranged under each other.
- In the form of an overview table.

## Filtering

You can edit the filters above the timetable to hide actions that, for example, have already been accredited and you don't need to see the timetable.

- Filters can be set up in **Filters setup** tab in **Menu**.
- You can also use default filters by activity type.

![](filters_en.png)

## Date range selection

In the calendar, you have the option to manually set a from-to span to display the timetable, or you can use preset values.
